# Editable Alchemist 11 checkpoint

Open `alchemist-11-working.blend` in Blender 5.2.3 LTS (the authoring version).
This is the current user-saved model, including manual edits, with all used image
textures packed inside the file. It has no linked Blender libraries and does not
need the original machine's texture folders to display correctly.

Contents: More Alchemists variant 11, black outfit shader, retained red/gold
ornament and grey hood, Khainite dagger in the right hand and handbow in the left.
Current hidden parts, other hidden reference models, pose and material nodes are
preserved. The humanoid01e target has not received a final animation integration.
The hidden humanoid01d reference rig supplies only native grip alignment.

The Blender RMV2 addon is needed for subsequent game-format import/export, not
for opening and editing the saved meshes/materials. Game deployment is pending.
Original source packs: More Alchemists (`2854480153/!solaire_more_alchemists.pack`)
and native WH3 Khainite Assassin props. This is an editable project checkpoint,
not a release-ready game mod.

`portability.json` records the source checkpoint, file size and SHA256. The local
working file under `build/` is retained unchanged; use this tracked copy when
continuing on another machine.
